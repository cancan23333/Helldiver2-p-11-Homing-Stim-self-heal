[SIZE=5][B]它是什么 / What it is[/B][/SIZE]

[B]中文[/B]
把 [B]P-11 治疗剂手枪[/B] 变成一把[B]会自己找队友的治疗枪[/B]：扣下扳机，弹丸出膛后自动转向，追踪索敌范围内
[B]残血的友军[/B]，并且[B]开枪的同时也治疗你自己[/B]。

它锁定的是[B]友军[/B]，不是敌人：潜兵和 SEAF AI NPC。锁定优先度固定为：

[LIST=1]
[*][B]残血潜兵[/B]
[*][B]满血潜兵[/B]
[*][B]残血 SEAF[/B]
[*][B]满血 SEAF[/B]
[/LIST]

上一档永远压过下一档；同一档内，离准心最近的胜出。

[B]English[/B]
Turns the [B]P-11 Stim Pistol[/B] into a stim gun that [B]finds your teammates for you[/B]: pull the trigger and the
dart steers itself in flight toward a [B]wounded friendly[/B] inside your lock cone - and [B]heals you as you fire[/B].

It locks [B]friendlies[/B], never enemies: Helldivers and SEAF AI NPCs. The priority order is fixed:

[LIST=1]
[*][B]Wounded Helldiver[/B]
[*][B]Full-health Helldiver[/B]
[*][B]Wounded SEAF[/B]
[*][B]Full-health SEAF[/B]
[/LIST]

A higher tier always beats a lower one; inside a tier, whichever unit is closest to your crosshair wins.

[SIZE=5][B]亮点 / Highlights[/B][/SIZE]

[LIST]
[*][B]只改 P-11 / P-11 only[/B] —— 固定为 P-11 治疗剂手枪，不碰任何其他武器，也不改它的伤害、初速或弹道。 / Fixed to the P-11 Stim Pistol. No other weapon is touched, and the P-11 keeps its own damage, muzzle velocity and ballistics.
[*][B]锁定友军，四档优先度 / Friendly-only locking with the four-tier priority above[/B] —— 潜兵用「本地玩家自己的实体类型」判定（不需要外部哈希表，游戏更新也不会失效），SEAF 按[B]完整的 20 个身体白名单[/B]放行。 / Helldivers are recognised by the local avatar's own entity type (no external hash list, so it cannot go stale); SEAF are admitted from a [B]complete 20-entry whitelist[/B] of every SEAF body.
[*][B]射击时自我恢复 / Heal yourself when you fire[/B] —— 真实开枪就给自己回血。挂的是运行时的 [FONT=monospace]player_fired[/FONT] 事件（游戏自己的 [FONT=monospace]projectiles_fired[/FONT] 统计），所以[B]换弹、拔枪、空扳机都不会回血[/B]；回血走游戏自己的 [FONT=monospace]AddHealthFraction[/FONT]，[B]自动封顶到最大血量[/B]，倒地或死亡时会被拒绝。还能[B]顺便修复部位损伤[/B]（头/胸/双手/双膝）。[B]不写内存、不改游戏数据。[/B] / A [B]real[/B] shot heals you. It hooks the runtime's [FONT=monospace]player_fired[/FONT] event (the game's own [FONT=monospace]projectiles_fired[/FONT] stat), so reloading, drawing the pistol or dry-firing heals nothing; the heal is the game's own [FONT=monospace]AddHealthFraction[/FONT] - it clamps at maximum health and is refused while you are downed or dead. It also repairs [B]limb damage[/B] (head / chest / hands / knees). [B]Nothing is written to memory and no game data is patched.[/B]
[*][B]屏幕锁定 UI / On-screen lock UI[/B] —— 索敌[B]范围圆环[/B]、目标身上的[B]锁定标记[/B]（锁定完成时旋转收拢）、目标外面的[B]锁定部位方框[/B]，三者各自独立开关。 / A [B]range ring[/B], the stock [B]lock markers[/B] on the target (they spin in as the lock completes) and a [B]wire box[/B] on the locked unit - each with its own switch.
[*][B]掩体判断 / Cover check[/B] —— 你和目标之间有实体挡住时不锁定。射线[B]从枪口发出[/B]，判的就是子弹这条路，而不是相机的视线。 / A unit with no line of sight is not locked. The ray is fired [B]from the muzzle[/B], so it tests the path the dart would actually take rather than the camera's.
[*][B]自己绑定目标 / Bind the target ourselves[/B] —— 引擎没锁上时由 mod 在瞄准锥里挑一个绑上去，建议保持开启。 / When the engine does not lock by itself, the mod picks one inside the aim cone and binds it. Recommended to leave on.
[*][B]菜单自动双语 / The MODS tab follows your language[/B] —— [B]简体中文和繁体中文显示中文，其它任何语言显示英文[/B]，而且在游戏内改语言[B]不用重启[/B]就会跟着变。 / The MODS tab shows Chinese for Simplified and Traditional Chinese and [B]English for every other language[/B], and it follows a language change in game [B]without a restart[/B].
[*][B]实时可调 / Tune it live[/B] —— 12 个选项全部在游戏内 MODS 菜单里，含两个滑条；只占 [B]1 个分类[/B]，不会挤掉别的 mod 的分类按钮。 / All 12 options live in the in-game MODS tab (including two sliders) and use [B]one single category[/B], so no other mod's category button is pushed off the tab.
[*][B]F7 一键复位 / F7 to reset[/B] —— 偶发「锁不上」时按 F7：把写过的值全部还原再重新武装，不用重开游戏。 / When it occasionally stops locking, press F7: everything written is restored and re-armed, with no need to restart the game.
[/LIST]

[B]提示：[/B]范围环的屏幕半径是 [FONT=monospace]tan(锥角) × (屏高/2) ÷ tan(视场角/2)[/FONT]，
所以[B]锥角只有小于当前视场角的一半时，圆环才留在屏幕内[/B]。出厂值 15° 在所有视场角下都看得见；
调到 30° 左右，开镜时圆环就会跑出屏幕。 / [B]Tip:[/B] the ring's radius is
[FONT=monospace]tan(angle) × (screen height / 2) ÷ tan(fov / 2)[/FONT], so it stays on screen only while the angle is
narrower than [B]half your current FOV[/B]. 15 degrees stays visible at every FOV; around 30 it leaves the screen
when you aim down the sights.

[SIZE=5][B]已知问题 / Known issues[/B][/SIZE]

[LIST]
[*][B]主机视角下，别人看你射击会出现粉色问号 / Pink question mark when YOU are the host[/B]
本 mod 必须把弹丸换成带制导组件的实体，而[B]这个实体由射手生成并同步给其他人[/B]，所以[B]每台机器都必须自己备好它的资源包[/B]。
[B]没装本 mod 的机器上没有这个资源包，就会把你的弹丸画成一个粉色问号。[/B]
这是游戏机制（资源加载是本机的），[B]无法从本机修复[/B]，也不是本 mod 的 bug。
缓解办法：让队友也装本 mod；或队里有人[B]带着 P-92 法令手枪[/B]（那样该资源包会常驻）。 /
The mod has to swap the projectile for an entity that carries the guidance component, and [B]that entity is spawned by the shooter and replicated[/B], so [B]every machine must already have its package loaded[/B]. A machine that does not run this mod has no such package and draws your dart as a pink question mark. This is game behaviour (asset loading is per machine), it [B]cannot be fixed from your side[/B], and it is not a bug in this mod. Mitigation: have your teammates install this mod too, or have someone in the lobby [B]carry a P-92 Warrant[/B] (which keeps the package resident).

[*][B]做为客机时可能不会出现问号 / As a CLIENT the question mark may not appear[/B]
[B]推荐以客机身份加入别人的房间[/B]：房主（主机）通常已经带着把他的弹丸资源包加载好了，所以你看到的弹丸模型多半是正常的。 /
[B]Joining someone else's lobby as a client is recommended:[/B] the host has usually already loaded the package for their own dart, so the model you see is most likely correct.

[*][B]可能会出现个别 SEAF 无法锁定 / A few individual SEAF may not lock[/B]
SEAF 是按[B]实体类型哈希白名单[/B]放行的。如果游戏版本更新后出现新的 SEAF 型号、或者某个单位的实体类型不在名单里，
它就会[B]完全进不了候选[/B]。遇到时请把日志里的 [FONT=monospace]SCAN not-admitted entity types[/FONT] 那行发出来，
那一行会直接打出被拒绝的实体哈希，加进名单即可。 /
SEAF are admitted from a [B]whitelist of entity-type hashes[/B]. If a game update adds a new SEAF variant, or a unit's
entity type is not in the list, it [B]cannot enter the candidate list at all[/B]. If you hit one, send the
[FONT=monospace]SCAN not-admitted entity types[/FONT] line from the log - it prints the refused hash directly.

[*][B]和 Guided Rounds 同时启用会冲突 / Conflicts with Guided Rounds[/B]
两者都会抢 P-11 的设置行。请[B]只启用其中一个[/B]。 / Both claim the P-11's settings row. Enable [B]only one[/B].

[*][B]SEAF 不一定每次都测得到 / SEAF may not always be testable[/B]
SEAF 只在[B]带对应词条的星球[/B]上出现；没有词条时呼叫 SEAF 增援会让游戏在鹈鹕落地后崩溃。潜兵那条路在双人游戏里随时可测。 /
SEAF only spawn on [B]planets with the right modifier[/B]; calling SEAF reinforcements without it crashes the game after
the Pelican lands. The Helldiver path is testable any time in a two-player game.

[*][B]不开加速/耐力 / No speed or stamina buff[/B]
一针兴奋剂在游戏里做三件事：回血、修部位、给几秒加速。本 mod 做到[B]前两件[/B]；加速属于状态效果，运行时
[B]明确不支持[/B]施加 stim 类状态，所以做不到。 /
A stim does three things: heals, repairs limbs, and grants a few seconds of speed. This mod does the [B]first two[/B];
the speed part is a status effect and the runtime [B]does not support[/B] applying stim-type statuses.
[/LIST]
